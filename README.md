# Stock Market Analysis Dashboard

## Overview

This project analyzes historical stock prices and revenue data for Tesla and GameStop using Python.

## Technologies Used

* Python
* Pandas
* yfinance
* BeautifulSoup
* Requests
* Matplotlib

## Features

* Stock data extraction from Yahoo Finance
* Revenue data extraction through web scraping
* Data cleaning and preprocessing
* Trend visualization
* Business insight generation

## Results

### Tesla

Tesla showed strong revenue growth accompanied by a significant increase in stock price.

### GameStop

GameStop's stock price increased sharply despite relatively stable revenue, highlighting the impact of market sentiment.

## How to Run

```bash
pip install yfinance pandas requests beautifulsoup4 matplotlib
```

Run the Jupyter Notebook:

```bash
jupyter notebook
```
